# 🐚 Shell Scripting

## 📌 What is Shell Scripting?

Shell Scripting is the process of writing a sequence of Linux commands in a file so they can be executed automatically.

Instead of performing repetitive tasks manually, we write scripts to automate them, making the process faster, more reliable, and less error-prone.

---

# 🚀 Why Shell Scripting?

Imagine you need to create **100 EC2 instances**.

Doing it manually would:
- Take a lot of time
- Increase the chances of human error
- Be difficult to manage

Using Shell Scripting, the same task can be automated with a script.

Automation is one of the core principles of DevOps.

---

# 🎯 Why DevOps Engineers Learn Shell Scripting?

Shell scripting helps DevOps Engineers to:

- Automate repetitive tasks
- Deploy applications
- Monitor servers
- Check CPU, RAM and Disk usage
- Analyze log files
- Create backups
- Schedule jobs using Cron
- Manage Linux servers
