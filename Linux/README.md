# 🐧 Linux Fundamentals

## What is Linux?

Linux is an open-source operating system widely used in servers, cloud computing, DevOps, and enterprise environments.

---

## Why Learn Linux?

Linux is the backbone of modern cloud infrastructure. Most servers running on AWS, Azure and Google Cloud use Linux.

As a DevOps Engineer, Linux is required for:

- Server Administration
- Automation
- Monitoring
- Troubleshooting
- Deployments
- Cloud Computing
